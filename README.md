# DRIFT LEGENDS

スマホでもPCでも遊べる、3D峠ドリフトレーシングゲーム。

## 遊び方

GitHub Pages で公開すると、ブラウザでURLを開くだけで遊べます（インストール不要）。

- **PC**：W/S アクセル・ブレーキ、A/D ハンドル、Space サイドブレーキ、E ニトロ、C カメラ、Esc ポーズ
- **スマホ**：画面のボタンで操作（ジャイロ操作にも対応、設定から切り替え）

## 収録モード

- ストーリー / タイムアタック / 峠チャレンジ / フリードライブ
- ガレージ・カーショップ・チューニング・カスタマイズ
- チェスト（5種類・レア度5段階）と日替わりショップ
- 限定アイテム114種類（デカール、カラー、ホイール、ネオン、キャリパー、チューニングパーツ、ホーム背景、限定車）
- クリスマスイベント

## この版について

- セーブデータはブラウザ（端末）に自動保存されます。
- オンライン対戦とクラウドセーブは claude.ai 版だけの機能のため、この版には入っていません。

## 構成

`index.html` 1ファイルだけで動きます（3D描画・物理・音楽まで、すべて JavaScript で自作）。
